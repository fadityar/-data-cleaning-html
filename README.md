# Data Cleaning Demo (HTML)

Proyek ini adalah demo sederhana berbasiskan HTML/JS untuk memperlihatkan operasi pembersihan data dasar pada file CSV.

Fitur:
- Unggah file CSV
- Preview data
- Trim whitespace
- Hapus baris kosong
- Hapus duplikat (berdasarkan semua kolom)
- Konversi nilai numeric sederhana
- Download hasil sebagai CSV

Cara pakai:
1. Buka `index.html` di browser.
2. Pilih file CSV (kolom header di baris pertama).
3. Gunakan tombol untuk melakukan pembersihan.
4. Download hasil jika perlu.

Catatan:
- Parser CSV di proyek ini sederhana; untuk dataset kompleks gunakan library seperti [PapaParse](https://www.papaparse.com/).
- Project ini cocok sebagai materi pengantar/data cleaning untuk tugas atau workshop singkat.
